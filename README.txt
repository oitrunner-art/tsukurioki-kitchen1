わが家の作り置きキッチン（PWA）

ファイル
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面アプリ設定
- sw.js: オフライン用キャッシュ
- icon-192.png / icon-512.png: アプリアイコン

重要
このZIPを展開して index.html を直接開くだけでも動作確認できますが、
iPhoneのホーム画面にWebアプリとして追加し、オフラインキャッシュを有効にするには、
HTTPSで公開されたWebサイトとして配信する必要があります。

公開方法の一例（GitHub Pages）
1. GitHubにログインし、新しい公開リポジトリを作成する。
2. ZIPを解凍し、5ファイルをリポジトリのルートにアップロードする。
3. リポジトリの Settings > Pages で、Deploy from a branch / main / root を選んで保存する。
4. 表示された https://<ユーザー名>.github.io/<リポジトリ名>/ のURLをiPhoneのSafariで開く。
5. 共有ボタン > ホーム画面に追加 > 「Webアプリとして開く」があればオン > 追加。
6. アプリアイコンから起動して、献立・チェック・メモが保存されることを確認する。

データ
買い物チェック・作業チェック・メモは同じブラウザのlocalStorageに保存されます。
同じ端末でもブラウザを変えると別データになります。サイトデータの削除で消える場合があるため、
「メモ」タブから定期的にバックアップを保存してください。
